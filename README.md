# 🔎 Searching and Sorting Algorithms Visualized

This project demonstrates classic **Searching** and **Sorting** algorithms using C++, along with runtime comparisons. Below you can find visual step-by-step animations for better understanding.

---

## 📦 **Algorithms Included**

✅ Merge Sort  
✅ Quick Sort  
✅ Binary Search  
✅ Exponential Search

---

## 🖥️ **Sorting Algorithm Visualizations**

### 📊 Merge Sort

![Merge Sort Animation](https://upload.wikimedia.org/wikipedia/commons/c/cc/Merge-sort-example-300px.gif)

**Description:**  
Merge Sort divides the array into halves recursively and merges them in a sorted manner.

---

### ⚡ Quick Sort

![Quick Sort Animation](https://upload.wikimedia.org/wikipedia/commons/9/9c/Quicksort-example.gif)

**Description:**  
Quick Sort selects a pivot, partitions the array, and recursively sorts each part.
